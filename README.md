# System Design & Backend Engineering with AWS — Course Code Repository

Welcome to the official code repository for the **System Design and Backend Engineering with AWS (Season 3)** curriculum by Poridhi.

This repository hosts official codebases, seed datasets, configuration files, and starter templates for hands-on labs across all course milestones.

## Repository Usage

1. Clone this repository:
   ```bash
   git clone https://github.com/poridhioss/system-design-s3-codes.git
   cd system-design-s3-codes
   ```
2. Navigate to the relevant milestone and module directory for your active lab:
   ```bash
   cd Milestones/MileStone-04/Module-16a
   ```
3. Follow the corresponding lab instructions on the Poridhi platform to run, build, and test the project.
